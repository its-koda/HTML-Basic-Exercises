## 🇺🇸 English Version

### 📋 About the Repository
This repository contains basic HTML exercises created to practice the correct use of essential tags and build a foundation in web development.

### 🎯 Project Goal
Learn and apply the main HTML tags:  
- **h1 / h2** (titles and subtitles)  
- **img** (images)  
- **figurecaption** (image captions)  
- **link** (hyperlinks)
